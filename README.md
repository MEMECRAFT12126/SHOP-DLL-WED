## ✨ Características Principales

* **🎨 Diseño UI/UX Premium:** Estilo "Dark Mode" con paleta de colores `#121212` y acentos en azul neón `#3b82f6`.
* **✨ Efectos Visuales:**
    * Fondo de cuadrícula (Grid) animado.
    * Sistema de partículas interactivas (`Canvas API`).
    * Animaciones `Fade-in` al hacer scroll.
    * Emojis estilo Apple (Oni Mask 👹, Cohete 🚀, OVNI 🛸).
* **🔌 Integraciones:**
    * **Buzón de Sugerencias:** Conectado directamente a **Discord** mediante Webhooks.
* **📱 Totalmente Responsivo:** Adaptado para Móviles, Tablets y PC.
* **🚀 Navegación:** Botón flotante "Back to Top" (Cohete) y Scroll suave.
* **4️⃣0️⃣4️⃣ Personalizado:** Página de error con diseño único y animaciones.
